# opencode is the agent harness; we don't build our own loop

The AI chat runs on [opencode](https://github.com/anomalyco/opencode) (`opencode serve`, driven from the backend with `@opencode-ai/sdk`), not on a loop of our own. opencode brings the agentic loop, tool calling, streaming, file tools, skills (`SKILL.md`, incl. `.claude/skills`), `AGENTS.md`/`CLAUDE.md`, MCP and a permission system, and it talks to 75+ LLM providers, so the model is a config value and no provider is hard-wired. We rejected the Claude Agent SDK (proprietary and Claude-tuned; other models only through a proxy), pi (MCP and permissions only via extensions), Mastra and deepagents-js (more to build ourselves), and Gemini CLI / Crush (licensing, support). The hedge: only `apps/backend/src/harness/` knows opencode, behind a small ACP-shaped interface (session, prompt, update, tool call, permission events), so another harness (pi, Goose, claude-agent-acp via the Agent Client Protocol) could replace it without touching the frontend. The price: opencode's server API moves fast, so its image version is pinned and each upgrade has to re-check the confinement rules in [security.md](../../specs/system/security.md#confining-the-ai).
