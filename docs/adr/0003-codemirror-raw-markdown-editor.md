# The editor edits raw Markdown (CodeMirror 6), not WYSIWYG

The note editor is CodeMirror 6 on the raw Markdown text, with live preview done by decorations over that text. Obsidian is built on CM6 for the same reason. We rejected Milkdown/ProseMirror: a WYSIWYG editor parses the note into its own document model and re-serializes it on save, which normalizes formatting (list markers, emphasis, table padding). That means diff noise on every save and clashes with the AI, which edits the raw text, and frontmatter and `[[wikilinks]]` would need their own nodes to survive the round trip. With CM6 the text the user didn't touch stays byte-for-byte the same (CRLF included). If true WYSIWYG ever matters more than clean diffs, Milkdown is the alternative, but only with `prettier --parser markdown` run as a save hook on both sides (human and AI), so formatting is deterministic.
