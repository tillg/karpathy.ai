# Browser Only

Note: This is a research project only, we don't build it yet!!! 

Core question: Could we provide a similar functionality with just a browser app, i.e. w/o a server.

Thoughts:
- Files would have to be in the browser mem or on disk, in a way that browser can read & write them.
- The overall architecture in terms of "who calls whom" changes completely - we need a mermaid

Write an architecture report of how this could work:
- Architecture overview
- Options
- Areas that are difficult and why.
- Look for tools / packages that offer solutions
- If there are questions and you have one or more ideas on how you could solve it, pls run spikes & tests to evaluate, confirm or reject those ideas & theories.

The report is in HTML.
