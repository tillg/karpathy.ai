# md -> HTML

Note: This is a research project only, we don't build it yet!!!

We are getting more and more reports. We want a system that generates the HTML reports from `.md`
files. The transformation should be deterministic.

Write a report "md -> HTML" that explains:
- What we want to do
- How this could be done
- What the challenges are
- Reports should be stylable per project, so each project has its own report design
  (idea: different projects simply have different CSS)
